# 字靈傳說

HD-2D 風格（參考《歧路旅人》）的成語學習 JRPG 網頁遊戲，對象為小四學生。

故事：每個成語都是守護墨香鎮的「字靈」。亂字魔把字靈打散，主角是字靈守護者的後人，向鎮民學回成語喚醒字靈，最後打倒亂字魔。

## 執行

本機：雙擊 `start.bat`（需要 Node.js），會開 http://localhost:5173 。

放上網：整個資料夾是純靜態網站（three.js 已複製到 `vendor/`），可直接放上 GitHub Pages 等主機，不需要 `node_modules`。
更新 three.js 版本後執行 `npm install && npm run vendor`。

## 操作

- 方向鍵／WASD：移動
- 空白鍵／Enter：對話、確認
- B：成語冊　Q：任務　M：音樂開關
- 答題時可按 1–4 選答案
- 平板會顯示觸控搖桿與 A 鍵

## 已完成

- 職業：劍士、法師、弓手（開局選擇）
- 鏡頭：俯角 18°、偏航 0°、翻滾 0°、FOV 32°；精靈同樣傾斜 18° 正對鏡頭
- HD-2D 效果：即時光影、燈光泛光、移軸景深、暗角
- 主城：6 個 NPC，5 位各教 2 個成語（學完要答對小測驗），村長發佈任務；學會 5 個成語才可出城
- 郊區：看得見的怪物（史萊姆、野狼、哥布林），碰到就開戰；接了頭目任務後北端出現頭目
- 戰鬥：回合制，沒有普通攻擊；每個技能都要先答對成語題（只考已學過的）才能施放，答錯該回合失敗；頭目戰不能逃走，頭目會蓄力重擊
- 音樂音效（Web Audio 即時合成，暫代）
- 美術：手繪高清素材自動平滑取樣；暖色調、輕景深
- 成語冊、任務追蹤、存檔（瀏覽器 localStorage）

## 結構

- `js/data/`：成語、職業、怪物、NPC 與任務、美術素材清單（改內容主要改這裏）
- `js/world/`：Three.js 引擎、地圖、精靈、貼圖
- `js/overworld.js`、`js/battle.js`、`js/ui.js`、`js/quiz.js`
- `CODEX_ART.md`：給 Codex 直接閱讀執行的美術任務（generate2dsprite）

`CODEX_ART.md` 的 23 張透明精靈表已完成（128 影格）：三職業行走／戰鬥、六位 NPC、四種怪物和四種戰鬥特效，位於 `assets/sprites/`。啟動伺服器後重新整理遊戲即可載入；素材規格與檢查紀錄見 [素材說明](assets/sprites/README.md)。仍待決定的事項見 `docs/待決定事項.md`。
