# 故事方案（已選：方案二《字靈傳說》）

十個成語都是描寫心情的，所以三個方案都讓「心情」或「文字」成為故事核心，學成語就是推進劇情。

---

## 方案一：《心之寶石》
- **遊戲名稱**：成語小勇者：心之寶石
- **城鎮**：晨曦城
- **主角背景**：剛到晨曦城報到的見習冒險者（按開局職業為劍士、法師或弓手）。
- **故事**：城中央噴水池上的「心之寶石」被郊區的哥布林王偷走了，城民的心情從此變得亂七八糟：有人心灰意冷、有人心不在焉、有人怒髮衝冠。主角向居民學習成語，明白每一種心情，幫他們找回平靜，最後打倒哥布林王，把寶石放回噴水池。
- **頭目**：哥布林王（現在遊戲裏的暫定頭目）
- **特點**：最直接，改動最少；「心情」主題和十個成語最吻合。

## 方案二：《字靈傳說》
- **遊戲名稱**：字靈傳說
- **城鎮**：墨香鎮
- **主角背景**：守護墨香鎮的「字靈守護者」後人，今天第一天接受訓練。
- **故事**：每個成語原本都是守護小鎮的「字靈」。亂字魔把字靈打散，鎮民只記得一半的成語。主角向鎮民學回成語，等於喚醒字靈；戰鬥時答對題目，字靈就借出力量施放技能（解釋了「答對才能放技能」）。最後擊敗亂字魔，讓文字重回小鎮。
- **頭目**：亂字魔（身上浮着亂碼文字的暗影書怪）
- **特點**：遊戲規則和故事結合得最緊密；頭目需要另外設計。

## 方案三：《迷霧森林的試煉》
- **遊戲名稱**：成語冒險：迷霧森林
- **城鎮**：楓葉村
- **主角背景**：楓葉村學堂的學生，畢業前要完成村長安排的「冒險試煉」。
- **故事**：村外森林起了奇怪的迷霧，怪物變得暴躁。學堂老師和村民先教主角成語（學會五個才准出村），主角一邊完成村長的試煉任務，一邊查出迷霧來自森林深處的迷霧狼王，最後打倒牠，順利畢業。
- **頭目**：迷霧狼王（巨大的灰狼）
- **特點**：主角是學生，小四學生最有代入感；「學會五個才准出村」有自然理由。
