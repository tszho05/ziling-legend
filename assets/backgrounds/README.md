# 戰鬥遠景背景

依 `CODEX_ART.md` 第 9 節製作。每張 **2048×512（4:1）**。Codex 交付為不透明 PNG（每張約 1.3 MB），已轉成 JPG（品質 q3，每張約 150–240 KB）以加快網頁載入，用作 3D 戰鬥場景後方的遠景。

| 檔案 | 區域 |
| --- | --- |
| `battle_meadow.jpg` | 明亮上午的草原遠丘、淡藍山脈與白雲 |
| `battle_forest.jpg` | 綠霧中的層疊森林、遠處樹幹與金色光柱 |
| `battle_camp.jpg` | 橙粉黃昏下的遠方木柵欄、木塔及炊煙 |
| `battle_altar.jpg` | 紫色夜空、墨雲漩渦、遠處祭壇廢墟及浮石 |

預留上方約 35% 和左右各約 15% 的裁切範圍，主要景物安排於下方及中央。近處地面、道路、角色與場景物件由遊戲繪製。

美術使用 Codex 內建圖像生成工具製作與修正。後製只裁切畫幅、等比例縮放及輸出為不透明 RGB；沒有拉伸景物或以程式繪製背景。原始稿、修正稿、提示詞及裁切記錄位於 `output/art/batch5/`，不納入版本控制。

既有 `js/world/arena.js` 會按區域自動載入同名 JPG。啟動專案伺服器並重新整理遊戲後生效。

本機 [完整及安全裁切預覽](http://localhost:5173/output/art/batch5/preview.html) 可切換顯示整張圖或下方 65%／中央 70%。
