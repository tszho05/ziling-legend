# 字靈傳說：動畫素材

2026-09-27 完成 `CODEX_ART.md` 全部 27 張透明 RGBA PNG，共 144 影格，包括第二批 3 張怪物行走表及第三批字靈拍翼浮動表。檔名及格數與 `js/data/assets.js` 一致，重新整理遊戲即會載入。

英雄行走列序固定為下、左、右、上；怪物行走為面向右的 2×2 表，依左上、右上、左下、右下播放。戰鬥英雄面向左、怪物面向右；NPC 面向鏡頭。角色與怪物腳底統一在格高 96% 處，256 格為 y=246、384 格為 y=369（邊界不含末端）。攻擊保留與待機相同的身體縮放，四格依序預備、出招、命中／釋放、收招；飛行箭矢、火焰及刀光只出現在獨立特效表。

特效保留每格的原始位置與共用縮放：箭矢向左前進、治療光點向上升起。末格保留少量殘光供淡出。史萊姆的形狀變化是彈性壓縮與伸展。

全部角色先用內建圖像生成建立正面原型，再以原型生成動畫。基準為已驗收的劍士行走表。後製使用 `generate2dsprite` 與確定性的透明清理、切格、共用縮放、腳底對齊及預览合成；沒有用程式繪製角色。發光特效另經透明背景修正，去除洋紅污染。頭目的紫色符文屬於原有設計，保留獨立碎片。

第二批怪物行走用既有待機表作參考，保留外觀與共同縮放。史萊姆依序壓扁蓄力、拉長、圓形、落地壓扁，各格底部仍在同一基線，跳躍高度由遊戲加入。野狼四足交替小跑；哥布林左右腳交替，木棒和書輕微擺動。既有遊戲設定使用野狼 10 fps、史萊姆及哥布林 6 fps。

第三批 `fx_spirit.png` 使用正面金色光團原型製作四格拍翼循環，兩手捧空白書卷，保留透明小翅膀、柔光及少量光點。四格共用縮放，含光暈輪廓高約 69–70% 格高；水平中心固定，垂直有約 ±5 px 的輕微浮動，不使用地面角色的腳底基線。遊戲開場與結局已有 8 fps 循環載入設定，成語由遊戲另行顯示。

驗證涵蓋：27 個 runtime 路徑、PNG/RGBA、144 格非空、尺寸與格數、逐格透明外緣、主體不碰格邊、地面角色腳底基線、無純洋紅底色殘留，以及 runtime PNG 與已檢查輸出的逐位元組一致。27/27 素材路徑 HTTP 載入成功；怪物行走／待機對照頁及字靈深淺背景預覽已檢視。

本機製作資料位於 `output/art/`（依專案 `.gitignore` 不納入版本控制）：各角色的 reference、提示詞、原始生成稿、processed、delivery、GIF/WebP 及 QC JSON；總檢查為 `output/art/delivery-audit.json`，總覽為 `output/art/all-assets-preview.jpg`。匯出工具為 `process_art.py`，戰鬥比例記錄為各英雄目錄下的 `battle-scale-profile.json`。行走的非均勻原始間距使用 `regrid_walk.py` 完整切分；火焰跨過原始分格中線的部分使用 `pad_fx_grid.py` 重新補足透明邊距。

第二批的提示詞及修正稿位於 `output/art/monster_{slime,wolf,goblin}_walk/`；製作紀錄為 `output/art/monster-walk-production.md`，檢查結果為 `output/art/monster-walk-audit.json`，待機／行走並排圖為 `output/art/monster-walk-comparison.png`。史萊姆重新補足透明格邊；哥布林逐格修正步態後組表，所有後製均保留共同縮放，沒有逐格拉伸身體。

字靈的參考原型、原始動畫、提示詞及製作紀錄位於 `output/art/fx_spirit/`。先生成洋紅背景原型，再用內建圖像生成製作帶透明 alpha 的動畫，保留翅膀與柔光。確定性後製僅清理近乎不可見的透明雜點、切格、共同縮放及平移對齊；未重畫角色。`delivery/qc.json` 記錄各格位置、透明度及檔案雜湊；`delivery/preview.gif` 為深淺背景動畫。

啟動專案伺服器後，可開啟 [互動動畫預覽](http://localhost:5173/output/art/gallery.html)，切換行走方向、速度與深淺底色；[怪物待機／行走對照](http://localhost:5173/output/art/monster-walk-preview.html)及[字靈拍翼浮動預覽](http://localhost:5173/output/art/fx_spirit/preview.html)可暫停逐格檢視。這些頁面為本機美術檢查工具。
