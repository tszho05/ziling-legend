# 字靈傳說：動畫素材

2026-09-26 完成 `CODEX_ART.md` 全部 23 張透明 RGBA PNG，共 128 影格。檔名及格數與 `js/data/assets.js` 一致，重新整理遊戲即會載入。

| 類別 | 張數 | 格數 | 每格 | 整張 |
| --- | ---: | --- | --- | --- |
| 三職業行走 | 3 | 4×4 | 256×256 | 1024×1024 |
| 三職業戰鬥待機／攻擊 | 6 | 2×2 | 256×256 | 512×512 |
| 六位鎮民 | 6 | 2×2 | 256×256 | 512×512 |
| 史萊姆／野狼／哥布林 | 3 | 2×2 | 256×256 | 512×512 |
| 亂字魔 | 1 | 2×2 | 384×384 | 768×768 |
| 刀光／火焰／箭矢／治療 | 4 | 2×2 | 256×256 | 512×512 |

行走列序固定為下、左、右、上。戰鬥英雄面向左、怪物面向右；NPC 面向鏡頭。角色與怪物腳底統一在格高 96% 處，256 格為 y=246、384 格為 y=369（邊界不含末端）。攻擊保留與待機相同的身體縮放，四格依序預備、出招、命中／釋放、收招；飛行箭矢、火焰及刀光只出現在獨立特效表。

特效保留每格的原始位置與共用縮放：箭矢向左前進、治療光點向上升起。末格保留少量殘光供淡出。史萊姆的形狀變化是彈性壓縮與伸展。

全部角色先用內建圖像生成建立正面原型，再以原型生成動畫。基準為已驗收的劍士行走表。後製使用 `generate2dsprite` 與確定性的透明清理、切格、共用縮放、腳底對齊及預览合成；沒有用程式繪製角色。發光特效另經透明背景修正，去除洋紅污染。頭目的紫色符文屬於原有設計，保留獨立碎片。

驗證涵蓋：23 個 runtime 路徑、PNG/RGBA、128 格非空、尺寸與格數、逐格透明外緣、主體不碰格邊、腳底基線、無純洋紅底色殘留，以及 runtime PNG 與已檢查輸出的逐位元組一致。瀏覽器預覽已確認 23/23 成功載入；各動畫表和深淺底色預覽已檢視。

本機製作資料位於 `output/art/`（依專案 `.gitignore` 不納入版本控制）：各角色的 reference、提示詞、原始生成稿、processed、delivery、GIF/WebP 及 QC JSON；總檢查為 `output/art/delivery-audit.json`，總覽為 `output/art/all-assets-preview.jpg`。匯出工具為 `process_art.py`，戰鬥比例記錄為各英雄目錄下的 `battle-scale-profile.json`。行走的非均勻原始間距使用 `regrid_walk.py` 完整切分；火焰跨過原始分格中線的部分使用 `pad_fx_grid.py` 重新補足透明邊距。

啟動專案伺服器後，可開啟 [互動動畫預覽](http://localhost:5173/output/art/gallery.html)，切換行走方向、速度與深淺底色。此頁為本機美術檢查工具。
